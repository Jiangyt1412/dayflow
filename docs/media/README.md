# DayFlow product media

Current set: **1.7.1**, created October 19, 2026.

- `hero-v171.png`: current icon, Tasks and a task-linked timer, arranged in a cream/sage campaign layout.
- `product-showcase-v171.png`: actual Tasks, Focus and category-pie screens.
- `daily-rhythm-v171.png`: actual sleep intervals and Notes/history.
- `dayflow-demo-v171.gif`: a shortened inline animated preview for the repository README.
- `dayflow-demo-v171.mp4`: full silent recording, H.264 MP4.
- `demo-poster-v171.png`: title frame from the video stage.

Screenshots and recording come from the unmodified 1.7.1 production application with a fixed demonstration clock and isolated synthetic records. Times, chart values and task relationships are rendered by the application from those records. Surrounding copy, framing and transitions are presentation artwork. No personal backups were used or published. The current pixel-art icon was supplied by the project owner.

The video shows real task completion and saving, timer start/pause/resume/finish, category-to-task pie navigation, sleep intervals and saving a Notes entry. It has no music or voice-over. Native iPhone keyboard, picker, status-bar blur and hardware feedback are not demonstrated by this desktop browser recording.

Older media files remain for link compatibility; the READMEs reference only this current set.
